Textures ported from SoupVisuals 1.21.11 (soupapi) by Padej_.

Original paths -> paths here:
  assets/minecraft/textures/circles/*.png        -> silkvis/textures/soup/circles/*.png
  assets/minecraft/textures/particles/glyph/*.png    -> silkvis/textures/soup/particles/glyph/*.png
  assets/minecraft/textures/particles/glyph_alt/*.png -> silkvis/textures/soup/particles/glyph_alt/*.png
  assets/minecraft/textures/legacy/*.png         -> silkvis/textures/soup/legacy/*.png

The particle "mode" presets (star, heart, bloom/, flame, coron, dollar, snowflake,
geometric, virus, firefly, blink, soupapi_2, soupapi_3) live in silkvis/textures/soup/particles/
and were copied with batch 1.

legacy/ holds the nine marker textures of FriendsTargetRender. The original also ships
legacy/rockfly.png; no option of the 3.2.0 settings references it, so it is not copied.
