# Ручная проверка приёмки

Проверять только на собранном jar в настоящем клиенте 1.21.10 (не `runClient`). Ни одна
строка ниже не считается проверенной, пока в колонке «Факт» не стоит результат.

Правило доказательств (TEST-06): факт = наблюдение + номер версии jar + скриншот или
три строки из `latest.log`. «Работает» без этого — не факт.

## Как запускать

```powershell
cd F:\silkvis
git pull
.\build.bat
```

Jar: `build\libs\silkvis-<версия>+mc1.21.10.jar` → `%appdata%\.minecraft\mods`.
Прошлый jar удалять: два SilkVis одновременно загрузят дубли обработчиков событий.

## Чего в этой версии нет (не считать багом)

GPU-текстура карты, полноэкранная карта со слоями Slice, поиск по точкам, Now Playing
без бэкенда Windows, анимации переходов, PERF-бюджеты (не измерялись), Xaero-интеграция
(нет артефакта под 1.21.10).
