# Порядок сборок

Одна таблица, чтобы по названию было видно, какая это сборка и что в ней.
Версия берётся из `gradle.properties` → `mod_version`, попадает в имя jar, в лог сборки
(`[SilkVis] BUILD ...`) и в `latest.log` при старте игры.

## Правило нумерации

- **Большая версия** — новая крупная тема (например, 0.1.20 — автоматизация). Меняется
  вторая цифра после `0.1.`
- **Малая** — доработки внутри большой: `-v1`, `-v2`, `-v3`…
- Ветка называется так же, как версия, которую она делает, — иначе через десяток сборок
  не понять, что в какой ветке.

## Как добавить запись

1. Поднять версию в `gradle.properties` (`mod_version`).
2. Добавить строку в таблицу выше: версия, ветка, одна фраза о содержании.
3. `docs/status-report.md` — подробное описание, если сборка того заслуживает
   (там развёрнутые разделы по каждой версии, начиная с 0.1.13).
