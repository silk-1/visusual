# ADR-0010. HandTweaks: настройки без точки инъекции

- Статус: **принято** (с ограничением)
- Дата: 2026-11-15
- Связано: ADR-0009, ADR-0002
- Контекст: перенос HandTweaks из SoupVisuals

## Контекст

Оригинальный HandTweaks делает ровно три вещи:

1. `swingType != Vanilla` — отменяет ванильный свинг и рисует свой
   (`matrix.translate/rotate` в `renderFirstPersonItem`).
2. `customTranslate*` / `customRotate*` / `mainHand*` / `offHand*` — двигает руку в первом лице.
3. `swingSpeed` — масштабирует прогресс свинга (`swingDuration`).

Всё это реализовано через `HeldItemRendererMixin` (инъекция в `renderFirstPersonItem`)
и `MinecraftClientMixin` (подмена `getAttackCooldownProgress`).

В 1.21.10 нет:

- `HeldItemRendererEvent` в Fabric API 1.21.10 (событие было удалено, замены нет);
- публичного способа перехватить `HeldItemRenderer.renderFirstPersonItem` без миксина;
- публичного доступа к `ItemRenderer`-цепочке первого лица.

Единственная альтернатива — миксин, то есть отдельное решение с риском для стабильности
сборки и с обязанностью поддерживать точку инъекции при каждой смене минорной версии.

## Решение

`modules/HandTweaks.java` переносится **целиком по данным и логике**, включая все 29
настроек, `applySwing(...)`, `applyHandOffset(...)`, `handScale(...)` и `swingDuration()`,
но **без вызова из клиента**. Настройки сохраняются и читаются, значения доступны,
анимационная математика покрыта самопроверками (`SoupVisualsChecks2.swingTransforms`).

В клиенте модуль виден в списке и настраивается; в документации он помечен как
`settings-only`. Когда в Fabric API появится хук первого лица (или будет принят ADR на
миксин), включение сводится к одной строке — вызову `applySwing` из обработчика.

## Последствия

- Нет миксина, нет риска сломать рендер руки при обновлении версии.
- Пользователь видит настройки, но не видит эффекта. Это записано в
  `docs/known-limitations.md` и в описании модуля, чтобы не выглядело багом.
- Порог входа для включения: `applySwing(matrix, swingProgress, rightHanded, hand)`
  возвращает `true`, если ванильный свинг нужно подавить; `applyHandOffset` — если
  нужен сдвиг руки. Обе функции уже написаны и проверены.
