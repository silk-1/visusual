# ADR-0005 — Собственная карта: identity, тайлы, квоты

- Статус: принято
- Дата: 2026-11-12

## Контекст

MAP-01..MAP-09: карта строится только по клиентским данным, без запросов к серверу и
без вычислений по seed. Нужны стабильная идентичность, версионированный формат тайлов,
атомарная запись, ограниченные кэши и сохранение пользовательских маркеров при чистке.

## Решение

1. `MapIdentity = worldProfileId + dimensionId + formatVersion + mode + sliceY`.
   `worldProfileId` — `sp-<hash>` для сохранения, `mp-<hash>` для `host:port`
   (порт входит в identity). Proxy/reset → `multiplayerSubWorld(...)`.
2. Тайл — 128×128 пикселей на LOD; LOD n = 2^n блоков на пиксель. `TileKey` включает
   identity, lod, tileX, tileZ. Отрицательные координаты считаются через `floorDiv`.
3. Формат `.svt`: magic `SVMT`, version, identity, mode/sliceY, lod, tileX/Z, revision,
   size, флаг высот, длина payload, CRC32 payload. CRC/структура не совпали → файл
   удаляется и тайл пересобирается независимо.
4. Запись: temp + atomic rename. Кэш CPU (`BoundedTileCache`) — LRU по байтам, стартово
   64 MiB; LOD-родители строятся даунсэмплингом 2×2.
5. Дисковая квота (стартово 512 MiB) удаляет самые старые тайлы; **маркеры и зоны
   лежат в отдельном `markers.json` и не затрагиваются**.
6. Сэмплирование: клиентский поток, бюджет 1 ms/tick, dirty-очередь coalesce по ключу
   тайла, публикация только для текущего `WorldSessionToken` (устаревшее отбрасывается).
7. Nether: режим `SLICE` с уровнем Y входит в ключ тайла; `SURFACE` для Nether по
   умолчанию не выдаётся за исследованную карту.

## Ограничения v1

- Текстурированный путь загрузки minimap отсутствует: `MinimapRenderer` рисует
  48×48 квадов из кэша (см. known-limitations), это осознанный временный слой.
- 3D cave map не обещается.
