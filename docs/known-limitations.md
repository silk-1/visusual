# Известные ограничения текущей сборки

Статус сборки: **V0/V1-каркас** (P0 завершён по коду, P1 частично). Ни один пункт ниже
не замаскирован в UI: недоступная возможность показывает причину.

## Блокирующие для эксплуатации

1. **Сборка не проверена.** В среде автора нет JDK и нет доступа к Fabric Maven,
   поэтому `gradlew build` не выполнялся. Версии закреплены по метаданным Fabric
   (`loom 1.19.4`, `yarn 1.21.10+build.3`, `loader 0.20.1`, `fabric-api 0.116.18+1.21.10`),
   а используемые API сверены по Yarn/Fabric API ветки `1.21.10` (таблица в
   `docs/dependency-matrix.md`). Это снижает риск, но не заменяет компиляцию.
2. **Клиент не запускался.** Скриншотов и in-game приёмки нет; все `UI-*`/`HUD-*`
   статусы — `IMPLEMENTED_NOT_TESTED`.
3. **Музыкальный backend отсутствует.** C++/WinRT helper не собран (нет Windows/MSVC).
   Провайдер вернёт `ERROR`, оверлей покажет «источник недоступен». Матрица
   совместимости (Spotify/YouTube/SoundCloud) не заполнена — её нельзя заполнять
   без реального прогона (7.4).
4. **Карта не отрисовывается текстурой.** `MinimapRenderer` рисует 48×48 квадов из
   кэша; загрузка тайлов в GPU-текстуру — следующий шаг. Сэмплер обращается к
   `BlockState.getMapColor` и `Heightmap` — сигнатуры 1.21.10 не проверены.

## Функциональные пробелы P1

5. Per-widget `scale` хранится и валидируется, но не применяется при рендере
   (нет проверенного API стека матриц) — ADR-0002.
6. Blur (UI-08) реализован как токен и настройка, сам эффект не рисуется.
7. Тема-ресурсы (ASSET-01..ASSET-04): нет загрузчика PNG/JPEG, HTTP-загрузки,
   custom sky и замены тотема. Валидация лимитов описана, реализация — V4.
8. Визуальные модули (VIS-01/02/03): настройки и валидация есть, mixin/hook для
   реального изменения FOV/тумана/частиц не добавлен (сознательно, до проверки API).
9. Музыкальные контролы в HUD не кликабельны: режим «Взаимодействие с HUD» есть как
   состояние и биндинг, но hit-testing кнопок оверлея не реализован (HUD-05).
10. Editor: drag/snap/guides/reset работают, но блокировка позиции, порядок слоёв и
    изменение размера виджета не реализованы; демо-данные подписаны как preview.
11. Поиск по модулям идёт по локализованному имени/описанию/id, но избранное и
    «изменённые настройки» пока без отдельного экрана.
12. Настройки языка в UI отсутствуют (RU/EN ресурсы есть, выбор — следующий шаг).
13. Keybind editor, color+alpha editor, file/URL picker, modal, toast UI — модели
    готовы (`TextInputModel`, `ToastManager`, `TooltipController`), виджеты не все.

## P2

14. Автоматизация отсутствует полностью и помечена «Запланировано» (A01..A22 готовы
    только как каталог со статусом PLANNED). Это соответствует 0.2 и жёсткому gate V5.

## Технический долг

15. `TileSampler` LOD 0 сэмплирует каждый второй блок и растягивает 2×2 — компромисс
    под бюджет 1 ms/tick; на слабых машинах потребуется измерение.
16. `PERF-*` бюджеты не измерены: нет запуска клиента, нет reference-машины.
17. В `ClientTileSampler` используется константа `0xFF000000` для альфы: это упаковка,
    а не цвет темы; в `render/` и `client/` нет hex-цветов UI.
