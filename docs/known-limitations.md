# Известные ограничения текущей сборки

Статус сборки: **V0/V1-каркас** (P0 завершён по коду, P1 частично). Ни один пункт ниже
не замаскирован в UI: недоступная возможность показывает причину.

## Блокирующие для эксплуатации

1. **Клиент запускается, но проверено не всё.** Первый успешный запуск — 2026-11-12
   (`0.1.1-p0`, MC 1.21.10 + Fabric API): игра стартует, `Right Shift` открывает меню,
   вкладки/тумблеры/слайдер работают, в мире рисуется HUD. **Не проверено:** `F1`,
   сохранение настроек между перезапусками, редактор HUD, перетаскивание виджетов,
   карта/тайлы, музыка, точки назначения, бюджеты PERF. По этому запуску найдено и
   исправлено 4 дефекта (`docs/status-report.md`, «Раунд 5»), но сами исправления в игре
   ещё не перепроверены.
   Версии сборки: `loom 1.19.4`, `yarn 1.21.10+build.3`, `loader 0.20.1`,
   `fabric-api 0.138.4+1.21.10`, Gradle 9.8.2, JVM сборки — JDK 25; у игрока достаточно
   `loader >=0.19.0` и любого Fabric API для 1.21.10 (`docs/install.md`).
2. **Музыкальный backend отсутствует.** C++/WinRT helper не собран (нет Windows/MSVC).
   Провайдер вернёт `ERROR`, оверлей покажет «источник недоступен». Матрица
   совместимости (Spotify/YouTube/SoundCloud) не заполнена — её нельзя заполнять
   без реального прогона (7.4).
3. **Карта не отрисовывается текстурой.** `MinimapRenderer` рисует 48×48 квадов из
   кэша; загрузка тайлов в GPU-текстуру — следующий шаг. Сэмплер обращается к
   `BlockState.getMapColor` и `Heightmap` — сигнатуры 1.21.10 не проверены.

## Функциональные пробелы P1

4. Per-widget `scale` хранится и валидируется, но не применяется при рендере
   (нет проверенного API стека матриц) — ADR-0002.
5. Blur (UI-08) реализован как токен и настройка, сам эффект не рисуется.
6. Тема-ресурсы (ASSET-01..ASSET-04): нет загрузчика PNG/JPEG, HTTP-загрузки,
   custom sky и замены тотема. Валидация лимитов описана, реализация — V4.
7. Визуальные модули (VIS-01/02/03): настройки и валидация есть, mixin/hook для
   реального изменения FOV/тумана/частиц не добавлен (сознательно, до проверки API).
8. Музыкальные контролы в HUD не кликабельны: режим «Взаимодействие с HUD» есть как
   состояние и биндинг, но hit-testing кнопок оверлея не реализован (HUD-05).
9. Editor: drag/snap/guides/reset работают, но блокировка позиции, порядок слоёв и
    изменение размера виджета не реализованы; демо-данные подписаны как preview.
10. Поиск по модулям идёт по локализованному имени/описанию/id, но избранное и
    «изменённые настройки» пока без отдельного экрана. В компактном режиме (UI-03:
    scaled width < 700) список модулей заменён настройками, поэтому поиску нечего
    фильтровать — поле выглядит рабочим, но результата не показывает. Это следствие
    правила UI-03, а не забытая функция: нужен либо результат-список поверх настроек,
    либо снижение порога WIDE (требует правки ТЗ).
11. Настройки языка в UI отсутствуют (RU/EN ресурсы есть, выбор — следующий шаг).
12. Keybind editor, color+alpha editor, file/URL picker, modal, toast UI — модели
    готовы (`TextInputModel`, `ToastManager`, `TooltipController`), виджеты не все.

## P2

13. Автоматизация отсутствует полностью и помечена «Запланировано» (A01..A22 готовы
    только как каталог со статусом PLANNED). Это соответствует 0.2 и жёсткому gate V5.

## Технический долг

14. `TileSampler` LOD 0 сэмплирует каждый второй блок и растягивает 2×2 — компромисс
    под бюджет 1 ms/tick; на слабых машинах потребуется измерение.
15. `PERF-*` бюджеты не измерены: запуск в игре уже есть, но reference-машины и
    методики замера (60 s прогрев, 120 s окно, 3 прогона) нет.
16. В `ClientTileSampler` используется константа `0xFF000000` для альфы: это упаковка,
    а не цвет темы; в `render/` и `client/` нет hex-цветов UI.
